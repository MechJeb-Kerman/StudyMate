# StudyMate · Python 算法与蓝桥杯

这是 StudyMate 学习工作区的**离线课件包**：一套静态网页，双击 `index.html` 就能看。
完全离线——不需要联网、不需要起服务、不需要装任何东西。

## 从哪开始

1. 双击打开 **`index.html`**（工作区根页面「我的课程」总览）
2. 从总览进科目，再从科目主页进 33 页课件

也可以跳一级直接进科目：
`.learning/subjects/python-algorithm-lanqiao/index.html`

> **请保持目录结构不要动。** 页面之间、页面与图片/样式之间都靠相对路径互相引用，
> 挪动任何一个目录都会让页面失去样式或断图。

## 两点说明

- 这是**静态页面**：题目可以点选、页面里也有「检查」按钮，但它**不记录作答数据**，
  做过的题不会存到任何地方，也不会同步学习进度。
- 页面里的外链（oi-wiki、Python 官方文档等）是正文的引用出处，是给人点的，不点也不影响阅读。
