Python 算法与蓝桥杯

进行中

学生准备参加蓝桥杯（Python 组），但拿奖本身不是目的——真正想要的是把 Python 的算法能力练起来：遇到一个没见过的问题，能自己建模、判断该用什么算法、估出复杂度，并写出能通过时间限制的代码。

在做的项目

AI 刷题助手（题目文本 → 大模型 API 分析题意 → 推荐候选算法 → 对拍器与样例自动验证候选解）
