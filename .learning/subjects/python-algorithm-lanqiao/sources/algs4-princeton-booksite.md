# Algorithms, 4th Edition

essential information that every serious programmer needs to know about algorithms and data structures

## Online content.

- *Excerpts.* A condensed version of the text narrative, for reference while online.
- *Lectures.* Curated studio-produced online videos, suitable for remote instruction via [CUbits](https://www.cubits.ai/collections/115).
- *Java code.* The algorithms and clients in this textbook, along with the standard libraries they use.
- *Exercises.* Selected exercises from the book and “web exercises” developed since its publication, along with solutions to selected exercises.
- *Programming assignments.* Creative programming assignments that we have used at Princeton.

## Textbook.

Algorithms, 4th Edition

Amazon

Pearson

InformIT

- [*Chapter 1: Fundamentals*](https://algs4.cs.princeton.edu/10fundamentals) introduces a scientific and engineering basis for comparing algorithms and making predictions. It also includes our programming model.
- [*Chapter 2: Sorting*](https://algs4.cs.princeton.edu/20sorting) considers several classic sorting algorithms, including insertion sort, mergesort, and quicksort. It also features a binary heap implementation of a priority queue.
- [*Chapter 3: Searching*](https://algs4.cs.princeton.edu/30searching) describes several classic symbol-table implementations, including binary search trees, red–black trees, and hash tables.
- [*Chapter 4: Graphs*](https://algs4.cs.princeton.edu/40graphs) surveys the most important graph-processing problems, including depth-first search, breadth-first search, minimum spanning trees, and shortest paths.
- [*Chapter 5: Strings*](https://algs4.cs.princeton.edu/50strings) investigates specialized algorithms for string processing, including radix sorting, substring search, tries, regular expressions, and data compression.
- [*Chapter 6: Context*](https://algs4.cs.princeton.edu/60context) highlights connections to systems programming, scientific computing, commercial applications, operations research, and intractability.
