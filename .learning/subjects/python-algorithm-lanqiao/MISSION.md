# Mission: Python 算法与蓝桥杯

## Why

学生准备参加蓝桥杯（Python 组），但拿奖本身不是目的——真正想要的是把 Python 的算法能力练起来：遇到一个没见过的问题，能自己建模、判断该用什么算法、估出复杂度，并写出能通过时间限制的代码。现在的情况是 Python 只会最基础的部分（函数用得不多），数据结构与算法都是零起点，所以这门课要从"为什么需要数据结构"开始搭，而不是从语法讲起。比赛在这门课里是检验手段：它提供真实的题目、真实的时限，和"你到底会不会"的诚实反馈。

## Success looks like

- 拿到一道没做过的蓝桥杯省赛难度的题，能独立说出它的数据规模、据此估出可接受的复杂度上限，并选出匹配的算法写出来、通过样例与边界数据
- 能亲手实现常见数据结构与算法（并查集、堆、哈希、排序、二分、BFS/DFS、DP 等），并与 Python 标准库的现成实现对照验证结果与性能差异
- 能对任何一个已学算法讲清三件事：它为什么正确、复杂度怎么推、在什么数据规模下会被淘汰——达到能讲给别人的深度
- 项目「AI 刷题助手」逐步长成可用工具：能输入题目文本、由大模型辅助分析题意、给出候选算法，并用对拍器与样例自动验证候选解

## Constraints

- 前置基础：Python 只会最基础的部分——循环、条件、基本列表字典会用，**函数不熟练**，推导式与常用内置函数没把握（学生自评）；**数据结构没学过**；**算法没学过**；无竞赛经历
- 时间投入：每周 10 小时以上，备赛强度，节点可以推进较快、内容可以给足深度
- 环境：Windows；Python 3.14.7 free-threading 构建（`E:\MC\CODE\Py\python3.14t.exe`，`sys._is_gil_enabled()` 为 False）；工作区工具环境在 `C:\Users\shark\StudyMate\.venv`（含 pypdf／PyYAML／jsonschema，也用于跑引擎的 schema 校验）
- 学习产物与练习载体：实验课以 **Python 源文件 + 测试脚本** 交付（在 `lab/` 下自己写代码、跑测试脚本自测）
- 讲法偏好：例子要贴近真实题目，不要脱离题目的抽象玩具例子
- 目标层级是"精通"：要讲原理与复杂度推导，不满足于背模板与结论

## Out of scope

- C/C++ 竞赛写法（指针、模板、STL 细节等与 Python 无关的内容）
- Linux 竞赛环境与交互式题目（本机为 Windows）
- 比赛报名、组队与赛制流程等非技术内容
- Python 工程化与部署（虚拟环境管理、打包、上云等不作为课程内容）
