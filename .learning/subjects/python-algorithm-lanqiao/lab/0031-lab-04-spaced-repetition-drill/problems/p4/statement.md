# P4 · 最长公共子串

**时间限制**：2 秒 ｜ **内存限制**：256 MB ｜ **本题分值**：100 分

## 题目描述

给两个只含小写字母的字符串 $S$ 与 $T$。

**子串**指原串中连续的一段（不是"子序列"）。求 $S$ 与 $T$ 的
**最长公共子串**的长度：也就是最大的 $L$，使得存在 $S$ 的一个长度为 $L$ 的
子串与 $T$ 的一个长度为 $L$ 的子串完全相同。

如果没有公共字符，答案是 $0$。

## 输入格式

第一行一个字符串 $S$。
第二行一个字符串 $T$。

两个字符串都只含 `a` 到 `z` 的小写字母，长度至少为 1。

## 输出格式

一行一个整数：最长公共子串的长度。

## 数据范围

| 子任务 | 分值 | $\lvert S \rvert$ | $\lvert T \rvert$ | 备注 |
| --- | --- | --- | --- | --- |
| 1 | 15 | $\le 100$ | $\le 100$ | 随便怎么做 |
| 2 | 20 | $\le 2000$ | $\le 2000$ | 平方级还撑得住 |
| 3 | 25 | $\le 10^5$ | $\le 10^5$ | 字母表只有两个字符 |
| 4 | 40 | $\le 10^5$ | $\le 10^5$ | 字母表是全部 26 个 |

对全部数据：$1 \le \lvert S \rvert, \lvert T \rvert \le 10^5$。

## 样例 1

输入

```text
ababc
babc
```

输出

```text
3
```

说明：`bab` 与 `abc` 都同时是 $S$ 与 $T$ 的子串，长度 $4$ 的没有，所以答案是 3。

## 样例 2

输入

```text
abcde
fghij
```

输出

```text
0
```

说明：两个串没有公共字符。

## 样例 3

输入

```text
aaaaa
aaa
```

输出

```text
3
```

说明：短的那个串本身是公共子串。

### 提示

**先说清一件事**："最长公共**子序列**"那套二维 DP 在这里**不能用**——
它的状态数是 $|S| \times |T|$。这道题的 $|S| = |T| = 10^5$，
$10^{10}$ 个状态，光是把表开出来就已经放不下了。

想两个问题：

1. 如果已经知道"有没有长度为 $L$ 的公共子串"这个判断怎么做，
   那么答案能不能靠**若干次这样判断**试出来？$L$ 的取值范围有多大？
2. 判断"有没有长度为 $L$ 的公共子串"，需要在两个串里各取出
   $|S| - L + 1$ 与 $|T| - L + 1$ 段，段数太多、逐段比也太慢——
   能不能把"一段子串"压成一个**能快速算出来的数**，用查表代替逐段比较？

这道题在时间上是本场的分水岭：它的思路不长，但要从零写对一条
"二分 + 字符串哈希"的链，加上自己验证，通常要一个多小时。
