# P2 · 四边形合并

**时间限制**：2 秒 ｜ **内存限制**：256 MB ｜ **本题分值**：60 分

## 题目描述

院子里有 $n$ 堆石子排成一行，第 $i$ 堆有 $a_i$ 个石子。

每次操作：挑**连续的三堆**石子，把它们合成一堆，新的一堆有这三堆之和那么多石子。
这次操作的**代价**就是这三堆石子数之和。

例如 $[1, 2, 3, 4, 5]$：先合前三个得 $6$，代价 $6$，变成 $[6, 4, 5]$；
再合这三个得 $15$，代价 $15$。总代价 $21$。

每次操作把堆数从 $L$ 变成 $L - 2$。所以只要 $n$ 是奇数，最后一定能合到只剩一堆。

**求合到只剩一堆的最小总代价。** 如果 $n$ 是偶数（永远合不到只剩一堆），
输出 $-1$。

## 输入格式

第一行一个整数 $n$。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$，用空格分开。

## 输出格式

一行一个整数：最小总代价；$n$ 是偶数时输出 $-1$。

## 数据范围

| 子任务 | 分值 | $n$ | $a_i$ |
| --- | --- | --- | --- |
| 1 | 12 | $\le 10$ | $\le 10^3$ |
| 2 | 18 | $\le 100$ | $\le 10^9$ |
| 3 | 30 | $\le 300$ | $\le 10^9$ |

对全部数据：$1 \le n \le 300$，$1 \le a_i \le 10^9$。

**注意**：和会超过 32 位（$n = 300$、$a_i = 10^9$ 时总量到 $3 \times 10^{11}$），
Python 的整数不会有问题，但别在别的语言里用 `int`。

## 样例 1

输入

```text
5
1 2 3 4 5
```

输出

```text
21
```

说明：$n = 5$ 只有一条合并路线（前三个、再三堆），代价 $6 + 15 = 21$。

## 样例 2

输入

```text
3
4 1 9
```

输出

```text
14
```

说明：只有一次操作，代价是 $4 + 1 + 9 = 14$。

## 样例 3

输入

```text
4
1 2 3 4
```

输出

```text
-1
```

说明：$n$ 是偶数，每次少两堆，$4 \to 2 \to$ 停住，合不到一堆。

---

### 提示

$n$ 只有 300，$O(n^3)$ 的量级是容得下的（$300^3 / 6$ 是百万级别）。
和普通"相邻两堆合并"的题不一样的地方在于：**这次是连续三堆一起合**，
所以"合到只剩几堆"本身也要记进状态——不然你不知道现在还能不能再合一次。

想清楚两件事：这个状态要怎么写？合并的代价该在什么时候记？
