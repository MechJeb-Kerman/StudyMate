# p1 · 各组测试数据（由 test_data.py 现算，种子固定）

| 组 | 这一组在考什么 | 怎么造的 |
| --- | --- | --- |
| `case01` | 样例 1：n = 6、k = 4，答案是 4 | 手算：h=4 → 2+0+0+1+1+1 = 5 ≥ 4，h=5 → 1 < 4 |
| `case02` | 样例 2：k = 100，而 h = 1 时刚好 194 个座位、h = 2 时只剩 97 个，答案是 1 | 手算：h=1 → 100+1+60+25+8 = 194 ≥ 100；h=2 → 50+1+30+12+4 = 97 < 100 |
| `case03` | 只有一个观众，答案 = 他的偏好高度 10^9 | 边界：n = 1，二分区间只有 10^9 一个候选 |
| `case04` | 200 个观众偏好都是 10^9、k = 200，答案 = 10^9 | 边界：所有 a_i 相同，count(h) 只在 h = a_i 处跳变 |
| `case05` | n = 2000 随机，k = 1234，看二分收敛对不对 | 数据本身是随机的，但种子固定 3101 |
| `case06` | n = 2×10^5、a_i ≤ 10^9：必须 O(n log V)，枚举高度做不完 | k 取总座位数的五分之一，答案落在中高位 |
