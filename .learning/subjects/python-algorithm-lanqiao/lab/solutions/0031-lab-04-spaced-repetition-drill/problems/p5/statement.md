# P5 · 雨天迷宫

**时间限制**：2 秒 ｜ **内存限制**：256 MB ｜ **本题分值**：80 分

## 题目描述

雨后的广场是一片 $n$ 行 $m$ 列的格子，你要从左上角 $(1,1)$ 走到右下角 $(n,m)$，
每一步只能上下左右走一格。每个格子是四种情况之一：

| 字符 | 是什么 | 影响 |
| --- | --- | --- |
| `.` | 没裂的普通地面 | 起点与终点一定是它 |
| `-` | 裂冰 | 见下面的代价规则 |
| `b` | 完整冰 | 见下面的代价规则 |
| `#` | 走不过去 | 不能踩 |

**走一格的代价**：

- 从一格 `-` 走到**另一格 `-`**（两块裂冰连着）：代价 $0$——裂缝连成一片，一步就跨过去了；
- 其余任何一步（踩上 `b`、踩上 `.`、或者从地面走向一格 `-`）：代价 $1$。

**求从 $(1,1)$ 走到 $(n,m)$ 的最小总代价。** 如果走不到，输出 $-1$。

## 输入格式

第一行两个整数 $n$、$m$。
接下来 $n$ 行，每行一个长度为 $m$ 的字符串，只含 `.`、`-`、`b`、`#` 四种字符。
保证 $(1,1)$ 与 $(n,m)$ 上的字符是 `.`。

## 输出格式

一行一个整数：最小总代价；走不到输出 $-1$。

## 数据范围

| 子任务 | 分值 | $n, m$ | 备注 |
| --- | --- | --- | --- |
| 1 | 20 | $\le 50$ | 网格很小，随便搜 |
| 2 | 25 | $\le 300$ | 平方级还撑得住 |
| 3 | 35 | $\le 1000$ | 需要 $O(nm)$ 的写法 |

对全部数据：$1 \le n, m \le 1000$，$nm \le 6 \times 10^5$。

## 样例 1

输入

```text
1 1
.
```

输出

```text
0
```

说明：起点就是终点。

## 样例 2

输入

```text
3 3
.bb
b.b
bb.
```

输出

```text
4
```

说明：这个网格里没有裂冰也没有墙，每走一步都是 $1$；最短要 4 步。

## 样例 3

输入

```text
2 3
.--
bb.
```

输出

```text
2
```

说明：从 $(1,1)$ 走到 $(1,2)$ 是"从地面走向裂冰"，代价 $1$；
$(1,2) \to (1,3)$ 是"裂冰走到裂冰"，代价 $0$；
$(1,3) \to (2,3)$ 是"从裂冰走向地面"，代价 $1$。总共 $2$。

## 样例 4

输入

```text
3 3
.#b
#b.
b.b
```

输出

```text
-1
```

说明：$(1,1)$ 右边和下边都是 `#`，走不出去（不能斜着走）。

---

### 提示

这是"边权只有两种（$0$ 和 $1$）的最短路"。普通 BFS 只在**每一步代价都一样**时才对。

想一想：队列里能不能让"代价 $0$ 的新格子"排在"代价 $1$ 的新格子"前面？
Python 的 `collections.deque` 两端都能压入，正好够用。
